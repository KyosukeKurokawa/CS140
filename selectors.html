CSS Selectors

Paragraph

1. Ways to select an item:

  • Element / Tag Selector: Selects all elements of a specific type (e.g., p, div, h1).
  • Class Selector: Selects elements with a specific class attribute, prefixed with a dot (e.g., .button).
  • ID Selector: Selects a single, unique element with a

    specific ID

    , prefixed with a hash (e.g., #header).
  • Attribute Selector: Selects elements based on an attribute or its value (e.g., input[type="text"]).
  • Pseudo-class Selector: Selects elements based on state or dynamic context (e.g., a:hover, li:first-child).

    • Combinator Selectors: Selects elements based on relationships (e.g., div > p for direct children, div p for descendants).

2. Difference between an ID and a Class:

ID: Unique within a page. Used to target a single, specific element. High CSS specificity.Class: Reusable. Can be applied to multiple elements on the same page, and a single element can have multiple classes.

3. Difference between SPAN and DIV:

DIV tag: An inline-block / block-level container by default. Takes up the full width available and starts on a new line. Used to group larger structural blocks of HTML.SPAN tag: An inline container. Takes up only as much width as its content and does not break onto a new line. Used to target specific inline text or small fragments.

4. Difference between DIV and Semantic Tags (HEADER, MAIN, FOOTER):

Unlike a DIV tag:, which is a non-semantic container with no inherent meaning, HEADER, MAIN, and FOOTER are semantic HTML5 tags that explicitly describe the purpose and structure of page content—defining introductory, primary, and concluding sections respectively.

5. Ways to select a color in CSS:

In CSS, colors can be defined using preset keywords, numeric color-space models like Hexadecimal, RGB/RGBA, and HSL/HSLA, or dynamic references: such as system keywords and CSS variables.
