Explain the difference between inline, embedded, and external CSS.
  • Inline CSS:Written directly inside an HTML element using the style attribute.
  • Embedded (Internal) CSS: Placed within a <style> tag in the <head> section.
  • External CSS: Stored in a separate .css file and linked using a <link> tag.
Explain why you should only use external CSS.
  • Maintainability: Update an entire website's design from a single file.
  • Cleaner Code: Separates HTML content from design rules.
  • Performance: Browsers cache external files to improve page load times.
What is a selector used for?
A selector targets specific HTML elements on a page (by tag, class, or ID) to tell the browser where to apply styling rules.
