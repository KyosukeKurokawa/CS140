Absolute and Relative Links Explanation and Usage

Absolute Link

An absolute link uses the complete web address of a website. For example, Nike is an absolute link. It is used when linking to a different website.

Relative Link

A relative link uses the file path of another page in the same website. For example, my profile page is a relative link. It is useful for connecting pages within the same website.
